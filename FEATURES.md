# Features

Status of tellem per feature. **Built** means merged on `main`; `v0.2.8`,
`v0.3.0`, and `v0.5.0` are tagged, and later patches carry no tag.
**Verified** names the run that showed it working and whether that run used a
real harness session, a replay or copy of one, a scratch fixture, or the real
record read only. The numbers come from `specs/tellem.impl.yml` (`as_built`
entries) and from the integration slices. **Deployed** says what runs on the
maintainer's host, checked on 2026-11-26. The hooks load from a linked runtime
checkout, separate from the working checkout, which moves only when it is
fast-forwarded and `rplugin install` is run.

On that host the cutover was applied on 2026-11-22 and again on 2026-11-23, and
`retention.native` is on. Claude Code and Codex are both at the `observe`
authority level, and Codex hooks are trusted, with real Codex sessions captured.
No SpecStory removal is applied, `transcripts.entries` is off, no mirror is
provisioned, the OpenTelemetry receiver is off, and nothing was promoted.

## Feature defaults

The manifest declares `features.capture`, `derive`, `transcripts`, `persona`,
`views`, and `mirror_sync`. All six default to true since the ship commit, once
the Codex hook run had recorded the real Codex payload keys. Every slice_4
verification above set them on at the user layer of the isolated home. A
fresh isolated install with the new defaults gives 0 findings from
`rplugin check`, `install`, and `doctor`.

The first SessionStart after install turns capture on. Every event checks only
the `capture.enabled` flag file. When that file is missing on a
`session_start` and `TELLEM_DISABLED` is not set, the hook loads the SDK
settings once and writes the flag if the resolved `features.capture` is true.
When the setting is false it writes `capture.settled` instead, and later
`session_start` events skip the SDK load. `tellem config set features.capture
true` writes the flag directly, so the marker never keeps capture off; a value
changed outside tellem shows up in `tellem doctor` with that command as the fix.
Each check below ran with no model calls, in fresh isolated homes (`rplugin
check`, `install`, and `doctor` at 0 findings), by piping a synthetic payload
into the installed `tellem-hook`:
